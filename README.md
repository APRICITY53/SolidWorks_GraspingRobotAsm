# SolidWorks 零件图、装配图和爆炸图

## 1. 零件图（Part）
- 用于表达单个零件的尺寸、形状、公差和材料信息。  
- 常见内容：主视图/俯视图/侧视图、尺寸标注、技术要求。  

## 2. 装配图（Assembly）
- 用于表达多个零件的装配关系与约束方式。  
- 常见内容：装配体视图、零部件序号（气泡）、BOM 明细表。  

## 3. 爆炸图（Exploded View）
- 用于表达装配体拆分后的层级和安装顺序。  
- 常见内容：爆炸步骤、连线、序号对应的零部件。  

## 推荐出图流程
1. 先完成每个零件的三维建模并生成零件图。  
2. 在装配环境中完成配合并生成装配图。  
3. 基于装配体创建爆炸视图，并在工程图中出爆炸图。
